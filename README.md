# Scatter & Bubble charts - VisuallyJs Vue

Scatter and Bubble charts are data visualization tools used to show the relationship between different variables. A scatter chart plots individual data points on a two-dimensional plane, while a bubble chart adds a third dimension by varying the size of the points. They are ideal for identifying correlations, clusters, and outliers in complex datasets.
